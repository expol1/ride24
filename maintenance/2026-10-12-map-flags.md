# Destination flags

Small local SVG country flags appear before destination names in the region
chooser and the selected-area heading. Azores and Madeira use Portugal's flag;
Sicily and Sardinia use Italy's flag. The mainland Portugal chooser caption is
shortened to “Portugalia” / “Portugal”; the detail heading retains “Portugalia
kontynentalna” / “Mainland Portugal”.

The 42 supported country flags are copied from flag-icons 7.5.0, MIT licence,
https://github.com/lipis/flag-icons, with the licence included in assets/flags.
They load from the website itself. Images are decorative; the accessible country
label remains text. A missing image is removed without hiding its label.

No location queries, location grouping, pick-up/drop-off handlers, database
records, bookings, saved tokens or Android code changed. Map asset query versions
are bumped so browsers load the new display layer.
